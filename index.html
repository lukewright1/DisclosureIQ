Email (SMTP)Not configured
Browser SMTP via EmailJS — this uses EmailJS.com (free up to 200 emails/month) to send real emails directly from this page without a backend server. Create a free account, connect your Gmail/Outlook/SMTP, paste your keys below, and emails will actually send.

For production use with higher volume, the backend will connect directly to your Microsoft 365 or SMTP server.
EmailJS configuration
Alternative: direct SMTP
Direct SMTP (Gmail, Outlook, etc.) requires a backend server for security — credentials can't be stored safely in a browser. Use EmailJS above for browser-based sending, or connect the DisclosureIQ backend when ready.
How to set up EmailJS
1
Go to emailjs.com and create a free account (200 emails/month free).
2
Add an Email Service — connect Gmail, Outlook, or any SMTP. Copy the Service ID.
3
Create an Email Template with variables: {{to_email}} {{subject}} {{message}}. Copy the Template ID.
4
Go to Account → API Keys and copy your Public Key.
5
Paste all three into the fields on the left and click Save, then Send test email to verify.
✓ Once configured, DisclosureIQ will send actual emails to clients when you use the Send screen.
